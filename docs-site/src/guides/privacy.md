# Privacy

{{name}} collects no data. Nothing you do with it leaves your browser.

- **What it stores:** your settings (where the control sits, when it shows, and
  whether to remember sizes) and the text size you chose for each website, by
  its address (for example `https://www.example.com`). They're kept in your
  browser's storage for add-ons and are never sent anywhere. Removing a site on
  the options page, or uninstalling {{name}}, deletes them.
- **What it reads:** to resize text, it looks at the text sizes of the page
  you're on, in your browser. It doesn't read, keep or send what the page says.
- **No tracking:** no analytics, no ads, no accounts, and no connections to any
  server. It loads no code from the internet; everything it runs is included in
  the add-on.
- **Why it can access every website:** so it can resize text on any page you
  visit, and apply your saved size when you come back.

Updates: if you installed it from this website (not from an add-ons store), your
browser checks this website for new versions. That request is made by the
browser itself, like any other web page, and {{name}} sends nothing with it.
