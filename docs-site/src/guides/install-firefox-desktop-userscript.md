# Install: Firefox Desktop (userscript)

This is the quickest way to try Text Size Adjuster, and works the same way in Chrome too.

1. Install a userscript manager add-on — [Tampermonkey](https://www.tampermonkey.net/) or
   [Violentmonkey](https://violentmonkey.github.io/) both work.
2. Download `text-size-adjuster.user.js` from the project's
   [releases](https://github.com/narve/text-size-adjuster/releases) (or build it yourself — see
   [the contributor section](../dev/index.html) if you're working from source).
3. Drag the downloaded file into a Firefox tab, or open it via the userscript manager's
   "Utilities → Import from file" option. The manager will show the script's details and ask you
   to confirm installation.
4. Visit any page. A small round control appears in the bottom-right corner with **−**, a
   percentage, **+**, a reset button, and a close button.

That's it — no further setup. See [how this differs from your browser's zoom/accessibility
settings](how-it-differs.html) if you're wondering why this exists alongside those.
