== Single purpose ==
Makes the text on web pages bigger or smaller while keeping the page's layout and pictures at their normal size, so pages are easier to read without zooming the whole page.

== Justification: storage ==
Saves the user's settings (where the on-page control sits, when it is shown, whether sizes are remembered) and the text size the user chose for each website, so that size is applied again on the next visit. Stored locally with chrome.storage.local; nothing is sent anywhere.

== Justification: host permissions ==
The extension's only job is resizing the text of the pages the user reads, on any website, and applying a remembered size automatically when the user returns to a site. That needs a content script on all sites, including frames inside a page, so that text in embedded parts of the page resizes together with the rest. The content script reads computed font sizes and writes scaled font sizes; it does not read, store or send page content.

== Remote code ==
No, I am not using remote code. All JavaScript is included in the package.
